# Arch Linux ARM WSL

[![Build](https://github.com/arfshl/archlinuxarm-wsl/actions/workflows/build.yml/badge.svg)](https://github.com/arfshl/archlinuxarm-wsl/actions/workflows/build.yml)

### [Download](https://github.com/arfshl/archlinuxarm-wsl/releases)

## Requirements
* xaarch64 based processors
* Windows Subsystem for Linux feature is enabled.

## Install
#### 1. [Download here](https://github.com/arfshl/archlinuxarm-wsl/releases)

#### 2. Double-click the .wsl file to install it with default name

#### 3. Or install from elevated cmd to customize the name

     wsl --install --from-file <path>/ubuntu-latest-amd64.wsl  --name <machine-name>
